# lazy-teach 與 /teach 的邊界＋畢業規則

lazy-teach 只服務「單一當下真實問題」的分鐘級微課：無 MISSION.md、無 Roadmap、無 Curriculum，不追蹤長期學習計畫。反向路由：同一主題被拉到第 3 次微課 → 必須提議畢業成正式 /teach 課程（有留痕的逃生艙）；使用者想要完整課程時也應直接去 /teach。

否決的替代方案：讓 lazy-teach 自己演化成完整課程系統——那會複製 /teach 的 12 檔重量，違反本 skill 存在的理由（低摩擦、立刻開課）。第 3 次門檻的依據：同一個洞需要挖三輪，代表它不是路障而是地基，值得系統性處理。
